কেন phpMyAdmin ক্র্যাশ করে আর টার্মিনাল কখনোই করে না? (টেকনিক্যাল কারণ) Why does phpMyAdmin Crash while Terminal Never Fails? (Technical Breakdown)
1. PHP Execution Architecture

phpMyAdmin মূলত একটি PHP ওয়েব অ্যাপ্লিকেশন। এটি যখন কোনো ১জিবি ফাইল আপলোড পায়, তখন upload_max_filesize, post_max_size এবং memory_limit সেটিংস চেক করে। নির্দিষ্ট সময়ের (max_execution_time যেমন ৩০ বা ৬০ সেকেন্ড) মধ্যে শেষ না হলে ওয়েব সার্ভার (Nginx/Apache) রিকোয়েস্ট কিল করে দেয়। phpMyAdmin is a PHP script subject to web server limits (max_execution_time, memory_limit). If a large import takes over 30s/60s, the web server abruptly kills the connection.

2. Direct UNIX Socket I/O

টার্মিনালে যখন আপনি mysql < backup.sql বা source কমান্ড দেন, তখন কোনো ওয়েব সার্ভার বা PHP ইন্টারপ্রেটার থাকে না। এটি সরাসরি লিনাক্স কার্নেলের UNIX Socket (/var/run/mysqld/mysqld.sock) দিয়ে মেমোরি পাইপের মাধ্যমে ডাটাবেজ ইঞ্জিনের কাছে বাইনারি স্ট্রিমে ডাটা পাঠায়। MySQL CLI connects directly via local UNIX domain sockets (/var/run/mysqld/mysqld.sock), bypassing HTTP layers and sending continuous raw data streams.

3. Granular Lock & Tuning Control

টার্মিনালে আপনি SET foreign_key_checks=0; এবং SET autocommit=0; দিয়ে InnoDB-র ইনডেক্স ও কনস্ট্রেইন্ট রিবিল্ড সাময়িক অফ করে দিতে পারেন। এতে প্রতি রো-তে ডিস্ক আই/ও না হয়ে সম্পূর্ণ ফাইল মেমোরিতে প্রসেস হয়ে একবারে কমিট হয়। CLI gives you precise session control to disable FK validations and autocommit buffers, speeding up bulk insertions up to 10x.

MySQL CLI সম্পূর্ণ কুইক রেফারেন্স চিটশিট MySQL CLI Quick Reference Cheat Sheet

প্রয়োজনীয় সব এক-লাইনার কমান্ড এক জায়গায় প্রিন্ট বা সেভ করে রাখার মতো ফর্মেটে।

1. Import & Export One-Liners
Import via Linux Shell
mysql -u root -p database_name < backup.sql
Import with Progress Bar (`pv`)
pv backup.sql | mysql -u root -p database_name
Export Full DB (Production Safe)
mysqldump -u root -p --single-transaction --quick database_name > backup.sql
Export and Gzip in One Go
mysqldump -u root -p --single-transaction database_name | gzip -9 > backup.sql.gz
2. Navigation & Inspection
List All Databases
SHOW DATABASES;
Switch Active Database
USE database_name;
List All Tables in Active Database
SHOW TABLES;
Inspect Server Status & Charset
STATUS;
3. Admin & Process Control
Create User & Grant All Permissions
CREATE USER 'app'@'localhost' IDENTIFIED BY 'pass'; GRANT ALL ON db.* TO 'app'@'localhost'; FLUSH PRIVILEGES;
Show Active Running Queries
SHOW FULL PROCESSLIST;
Kill Hanging Query Thread
KILL <PROCESS_ID>;
4. Turbo Import Speedup Commands
Disable FK Checks Before Source
SET foreign_key_checks = 0;
Re-enable FK Checks After Source
SET foreign_key_checks = 1;
Cancel Current Multiline Prompt
\c
